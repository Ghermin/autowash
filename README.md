# hermin-geoffrey.fr

This repository hosts my personal website — a small, non-commercial project I built for fun and learning.

Key points:

- Purpose: personal portfolio and playground. Not a product or commercial service.
- Tech: Vue 3 + Vite + TypeScript (see `src/` for the site code).
- Status: hobby project — expect occasional updates and experiments.

If you cloned this repo to explore the code or run it locally, the usual dev commands work:

```sh
npm install
npm run dev   # start dev server
npm run build # production build
```

Contributions and issues: welcome small, friendly PRs (minor fixes, typo corrections, accessibility improvements). Major changes or backwards-incompatible work will be declined — this is my personal site.
